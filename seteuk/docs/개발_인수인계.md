## 1. 프로젝트 개요
- 목적: 학생 점수 엑셀을 넣으면 **평가 항목별 문장을 1~10단계로 골라 조합**해 교과 세부능력 및 특기사항(세특) 초안을 만들고, 교사가 수정한 뒤 엑셀로 내보냄.

| ③ 항목 설정 | 점수 열(항목)마다 사용 여부, 표시 이름, 순서, 단계 변환(상대평가 백분위[전체/학급별] 또는 구간 직접 입력, 0점은 1단계 옵션), 문장 선택(무작위/순환), 단계 묶음(group) 편집, 프리셋(2/3/5/10구간), **은행에서 가져오기/은행에 저장**, 단계 분포 그래프, **🗂 카드 설명(desc)·사실 카드에 넣기(card)**. 발표 문제 코드 열이 있으면 **가상 항목** 4개(문제발표 횟수/최고난이도(기본1·도전2)/도전 수/가중점수)가 생김(기본은 가중점수만 사용, 문장 묶음은 생략) |

## 4. 핵심 데이터 구조 (index.html 내부)
```js
S = {
  book:  {fileName, names:[시트명], sheets:{시트명: [[셀...]]}} | null,   // 업로드한 학생 엑셀 원본
  cfg: {
    sheets: {시트명: {role:'score'|'ref'|'none', headerRow, cols:{열이름: 'key'|'name'|'class'|'score'|'none'},
                      matchCol, matchBy:'key'|'name', show:[열이름], probCol:'발표 문제 코드 열'|''}},     // ref 시트용 (probCol이 undefined면 rebuild()에서 guessProbCol()로 자동 추정)
    items:  {점수열이름: {label, enabled, method:'relative'|'range', scope:'all'|'class', zeroOne,
                         cuts:[11], groups:[{from,to,omit,sentences:'줄바꿈 구분'}], pick:'random'|'cycle', bank:'은행 항목명'}},
    order:  [점수열이름],  byteLimit:1500, sep:' ', subject:'과목',
    ai: {provider:'claudesub'|'gemini'|'claude'|'openai', tier:'quick'|'default'|'complex', model, key(브라우저에만 저장), list:{provider, ids}, ok:['provider:model'],
         fallback:true(과부하 시 ✅ 모델로 전환), gap:2(일괄 간격 초), req:''(AI 추가 요청, 마지막 값 기억)},
    flt: {unit:'c'|'b', min, max}   // ④ 분량 필터 (자/바이트)
  },
  edits: {학생키: {lv:{항목:단계}, sent:{항목:문장}, shift:{항목:n}, extra:'', final:null|'최종문장', memo:'교사 메모(줄마다 개조식)', must:['반드시 쓸 문제 코드'], hist:[{t,text,by}] (최종본 바뀌기 전 상태 최근 5개)}},
  bank:  [{subj:'공통'|'미적분Ⅰ'..., item, from, to, text, src, note}],
  subst: [{words:[유의어], rep:'대체표현'}],     // 문장은행 엑셀 「대체표현」 시트에서 불러옴 (+코드 내 SUBST_BUILTIN)
  probs: [{코드, 과목, 발표단원, …PCOLS 열 이름 그대로}]   // 문장은행 엑셀 「문제정보」 시트. 과목+코드로 합치기(같으면 갱신)
}
ST = [{key(학번 또는 학급|이름), kraw(학번), name, cls, fields:{열:값}, scores:{항목:숫자|null}}]
C  = {lv:{항목:{학생키:자동단계}}, cyc:{...}}   // recompute()에서 계산
```
- 주요 흐름: `rebuild()`(학생 목록 생성 → `ensureItems()` → `recompute()`) → `autoSentence()` / `sentenceFor()` → `generated()` → `finalText()`.
- 저장: `save()`는 localStorage(`seteuk_v1`)에 저장하고, 작업 파일이 연결돼 있으면 `writeFile()`도 실행. API 키는 `seteuk_aikey`에 따로 저장하고 백업에는 넣지 않음. 파일 핸들은 IndexedDB `seteuk/kv`의 `fh`.
- 작업 파일 형식: `{type:'seteuk-project', version:2, book, cfg(키 제외), edits, bank, subst, probs}`.
- 발표 문제: `parseCodes(칸)`은 칸 맨 앞의 세 자리 코드(여러 개는 쉼표 등으로 구분)를 뽑고 나머지를 메모로 돌려줌(예: `104,113 그래프로 설명`). `presented(s)`가 참고 시트의 `probCol`에서 학생 행을 찾아 `{code, memo, date, info:probFor(code)}` 목록을 만듦. `probFor()`는 현재 과목과 같은 과목의 문제를 우선(과목명은 Ⅰ→1 등으로 정규화해 비교). ② 문제 정보 표(`renderProbs`, 편집 모달 `editProb`)와 ① 참고 시트의 「🎤 발표 문제 코드 열」 선택(`probColStat`로 매칭 통계 표시).
- AI: `callAI(prompt, maxTokens, ms)` → API 키 모드는 `callOnce()`(제공자별 실제 요청, 실패 시 `e.status` 포함)를 `tryModel()`로 감쌈. `isBusy(e)`(429·5xx·529 또는 overload/high demand 문구)이면 `BUSY_WAIT=[3,8,15]`초 뒤 재시도(남은 초는 `AIW.note`로 `timed()`와 상단 `#status`에 표시). 그래도 실패하고 `fallback`이 켜져 있으면 `ok` 목록의 같은 제공자 다른 모델로 시도하고, 성공하면 `AIW.alt`에 10분간 기억해 다음 호출부터 바로 그 모델을 씀. 성공한 모델은 `markOk()`로 자동 ✅. 키·모델이 없으면 `openAICfg()`로 연결 창을 띄움. 연결 테스트(`testAI`)는 재시도·전환 없이 `callOnce`로 직접 확인. `fetchT`(AbortController 시간 제한), `timed()`(경과 초 표시).
- 추가 요청: `trimPrompt(text,target,req)`가 `reqLine(req)`를 기재요령 앞에 넣음. 일괄(`aiBatch`)은 `filtered()` 결과 전체가 대상, 학생 사이 `gap`초 대기, 과부하 연속 3명 실패 시 계속 여부를 물음. Claude 호출에는 `anthropic-dangerous-direct-browser-access` 헤더가 필요함. 지시문에 `RULES()`(기재 원칙 + 대체표현 목록)가 들어감.
- 모델 목록: `loadModels()` → `rankModels()`(미리보기·느린(pro/thinking/opus) 모델을 뒤로, 빠른 모델(flash/haiku·sonnet/mini) 우선, 그다음 버전 내림차순) → `renderModelSel()`.

## 5. 문장은행 엑셀 형식
- 「문장은행」 시트 열: `과목 | 항목 | 단계(부터) | 단계(까지) | 수준 | 문장 | 바이트 | 출처 | 비고`
  - 과목이 `공통`이면 모든 과목에서, 그 외는 상단 과목과 같을 때만 사용.
  - 단계 10이 최상. 수준: 9~10 최상, 7~8 상, 5~6 중, 3~4 중하, 1~2 하.
  - 문장 변수: `{이름} {과목} {항목} {점수} {단계} {탐구주제} {단원}`, 학생 엑셀의 `{열이름}`도 가능 (값이 없으면 그대로 남음).
- 「대체표현」 시트: `기재 유의어(쉼표 구분) | 대체표현`.
- 「문제정보」 시트: `코드 | 과목 | 발표단원 | 대단원 | 중단원 | 출처 | 쪽 | 구분(기본/도전) | 소문항 수 | 문제 요약 | 주제 구(20자 안팎 명사구, 세특에 그대로 쓰일 주제) | 핵심 개념 | 풀이 핵심 전략 | 어려운 지점 | 성취기준 코드 | 성취수준 근거 | 교과 역량 | 발표 시 드러나는 행동 | 세특 문장 예시 | 정답(검산) | 검토 | 비고`.
  - 코드 = 발표단원 순서 1자리 + 문제번호 2자리 (예: 113 = 1번째 발표단원 13번). 문제 파일 이름은 `미적분1-100.pdf`처럼 `과목-발표단원00`.
  - 「발표 시 드러나는 행동」은 풀이를 발표하면 반드시 드러나는 행동만 씀(AI 문장의 사실 근거, 과장 방지). 교과 역량은 2022 개정 수학과 5개(문제해결·추론·의사소통·연결·정보처리).
  - 문제 인식은 프로그램이 아니라 Claude Code 세션에서 PDF·사진을 직접 읽어 이 시트를 채우는 방식으로 함(API 비용 없음, 구독 모드 제약 없음). 정답은 수치 검산 후 기록.
  - 현재: 미적분Ⅰ 104~114 (미적분1-100.pdf = 교과서 Ⅰ-1 중단원 학습 점검 26~27쪽). 코멘트에 있으나 정보 없는 코드: 101, 102, 2xx, 3xx, 4xx → 해당 PDF를 받으면 추가.
- 그 밖의 참고 시트: 성취기준, 성취수준, 안내. 전체본(사용자에게만 전달)에는 문제해결_사례, 주제탐구_사례 시트도 있음.
- 현재 111문장: 공통(학업역량, 수업 태도, 수업 참여·발표, 과제 수행, 심화문제 발표, 수행평가(AI 프로그래밍)), 미적분Ⅰ(단원 이해 3개, 독서기반 탐구 프로젝트, 심화문제 단원별), 미적분Ⅱ·기하·확률과 통계(단원 이해, 각 3개).

## 7. 사용자 학생 엑셀 예시 구조 (참고)
- 학급별 시트(예: 「미적 2-3」): `학급 | 학년 | 반 | 번호 | 학번 | 이름 | 수업중 발표 | 발표(수행) | 칭찬 | 책검사(수행)(회차누적) | 익힘책(수행)(회차누적) | 합계`. 점수는 횟수(0~17). 마지막에 「합계」 행이 있을 수 있음(자동 제외).
- 회차별 상세 시트(「… 책검사(수행)」), 「코멘트 기록」 시트(`학급|학년|반|번호|학번|이름|항목|구분|값|날짜|시간|코멘트`) → 참고 시트로 사용. 「발표(수행)」 행의 코멘트에 발표 문제 코드(예: 414)를 적음 → 코멘트 열이 「발표 문제 코드 열」로 자동 지정됨.
- 열 구성은 매번 달라질 수 있어서 열 지정 방식으로 만듦.

## 8. 테스트 방법
- (Windows 데스크톱 앱) 저장소 `seteuk/`에서 `python -m http.server 8765 --bind 127.0.0.1` → 내장 브라우저로 `http://127.0.0.1:8765/index.html`. 학생 엑셀은 페이지 안에서 `XLSX`로 만들어 `DataTransfer`로 `#file`에 넣고 change 이벤트 발생. AI는 `window.fetch`를 가짜 함수로 바꿔 503·성공 응답을 흉내 냄. 시험 후 `localStorage.clear()`.

(이전 클라우드 작업 환경 기준)
- cdnjs가 막혀 있으므로 Playwright에서 SheetJS를 로컬 파일로 바꿔치기함:
  `npm i playwright@1.56.0 xlsx@0.18.5` (scratchpad) → `page.route('**/xlsx.full.min.js', r=>r.fulfill({path:'node_modules/xlsx/dist/xlsx.full.min.js'}))`, 브라우저는 `executablePath:'/opt/pw-browsers/chromium-1194/chrome-linux/chrome'`.
- **주의**: `setInputFiles`에 한글 경로를 주면 change 이벤트가 발생하지 않음 → 영문 파일명으로 복사해서 테스트.
- AI는 `page.route('https://generativelanguage.googleapis.com/**', ...)`로 가짜 응답(목록·성공·응답 없음)을 만들어 검증. CORS 헤더 `Access-Control-Allow-Origin:*` 필요.
- HWP 읽기: OLE 방식은 olefile + zlib으로 BodyText의 HWPTAG_PARA_TEXT(67)를 추출. HWPML(XML)은 `<CHAR>` 태그를 추출.

## 9. claude.ai 아티팩트 버전 (Claude 구독으로 AI 사용)
- 주소: https://claude.ai/artifact/WCng2Y4zijp8UNg7zm4NKm (비공개, 소유자만 열람). capabilities: `{sample:{}, downloads:true}`.
- **이 기능은 claude.ai 안에서만 동작함.** 다른 AI가 이 아티팩트를 직접 고칠 수는 없으므로, 수정한 `index.html`을 사용자가 Claude에 주고 "이 아티팩트 주소로 다시 게시해 줘"라고 요청해야 함. 다른 곳(파일 열기, GitHub Pages)에서는 자동으로 API 키 방식으로 동작함.
- 같은 `index.html`에서 `<!doctype>`·`<html>`·`<head>`·meta·`<body>` 줄만 빼고 게시함 (아티팩트가 뼈대를 씌움). 다시 게시할 때는 Artifact 도구에 `url`로 위 주소를 넘겨야 같은 링크가 유지됨.
- `window.claude.use`가 있으면 `IN_CLAUDE`로 판단하고, 이때 `claude.use('sample')`을 AI 제공자 `claudesub`로 씀(성능: quick/default/complex). `claude.use('downloads')`로 엑셀·백업을 저장하고, 작업 파일 자동 저장 카드는 숨김.
- 아티팩트 안에서는 `alert/confirm`이 막혀 있어서 페이지 안의 `dlg()/ask()/notice()` 모달로 바꿈. 일괄 다듬기는 Claude 구독 모드에서 6명씩 JSON 배열로 요청함.

## 10. 알려진 제한
- 엑셀 라이브러리를 CDN에서 받으므로 처음 열 때 인터넷이 필요함.
- 작업 파일 자동 저장은 크롬·엣지에서만 됨(File System Access API). 다시 열 때 「다시 연결」 버튼으로 권한을 다시 받아야 함.
- 영문 경고가 수식 표기(예: sin x)에도 뜸 (경고일 뿐).
