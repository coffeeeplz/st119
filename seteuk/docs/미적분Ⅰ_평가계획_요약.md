# 2026-2 미적분Ⅰ 평가 계획 요약 (세특 작성 참고)

## 성취기준
| 단원 | 코드 | 성취기준 |
|---|---|---|
| Ⅰ. 함수의 극한과 연속 | 12미적Ⅰ-01-01 ~ 04 | 극한의 뜻·성질, 극한값 계산, 연속을 극한으로 탐구, 연속함수의 성질 활용 |
| Ⅱ. 미분 | 12미적Ⅰ-02-01 ~ 10 | 미분계수, 미분가능성과 연속성, 도함수, 접선의 방정식, 평균값 정리, 증가·감소와 극대·극소, 그래프 개형, 방정식·부등식, 속도·가속도 |

## 평가 구성
| 영역 | 비율 | 내용 |
|---|---|---|
| 중간고사 / 기말고사 | 30% / 30% | 선택형+서답형 |
| 과정 중심 문제해결 성취 평가 | 20% | 학습 과정(필기·태도·참여) 30점, 수학익힘책 과제(7회) 30점, 문제해결 발표(3회) 40점 |
| 독서기반 탐구 프로젝트 | 20% | 도서 선정 → 핵심 내용 발췌 → 질문 생성 → 탐구 주제 설정 → 탐구·결론(개념+그래프) → 소감 → 발표 → 성실성 |

## 성취수준과 프로그램 단계 대응
| 성취수준 | 단계 | 특징 |
|---|---|---|
| A | 9~10 | 성질을 설명하고 다양한 문제에 활용하며, 그 과정을 설명함 |
| B | 7~8 | 이해하고 주어진 조건에서 구하며 문제에 활용함 |
| C | 5~6 | 알고 구할 수 있으며 간단한 문제를 해결함 |
| D | 3~4 | 간단한 함수에 대해 구하고 부분적으로 판정·활용함 |
| E | 1~2 | 안내된 절차에 따라 간단한 함수에 대해 구함 |

## 문장은행 항목 (과목 = 미적분Ⅰ)
- 단원 이해: 함수의 극한과 연속 / 미분 / 적분 (A~E 기준으로 작성)
- 독서기반 탐구 프로젝트 (채점 기준 기반, `{탐구주제}` 변수 사용 가능)
- 심화문제 발표 (단원별 예시)
- 수업 태도·수업 참여·발표·과제 수행은 「공통」 항목을 사용함
