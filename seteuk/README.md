# 세특 도우미

`index.html`을 크롬이나 엣지로 열어 사용합니다. 서버는 필요 없습니다. 처음 열 때 엑셀 라이브러리를 받아야 하므로 인터넷 연결이 필요합니다.

## 사용 순서
1. **과목 입력**: 맨 위 「과목」 칸에 입력합니다. 문장의 `{과목}` 자리에 들어가고, 과목별 문장 은행을 고르는 기준이 됩니다.
2. **② 문장 은행**: `data/문장은행_기본.xlsx`를 [엑셀 불러오기]로 넣습니다. 엑셀에서 고친 뒤 다시 불러오면 계속 업데이트됩니다. 기존 세특을 붙여넣으면 AI가 분류해 추가합니다.
3. **① 불러오기**: 학생 점수 엑셀을 올리고 시트 역할과 열 역할을 지정합니다.
4. **③ 항목 설정**: 항목마다 단계 변환 방식(상대평가 또는 구간 입력)을 고르고 [은행에서 가져오기]로 문장을 넣습니다.
5. **④ 학생별 작업**: 단계와 문장을 수정하고, 바이트와 기재 유의어를 확인하고, AI로 다듬습니다.
6. **⑤ 내보내기·설정**: 세특 엑셀 저장, 작업 파일 자동 저장 연결, AI 모델 선택을 합니다.

## 저장
- 브라우저 저장: 자동입니다. 캐시를 지우면 사라집니다.
- **작업 파일(.json) 연결(추천)**: ⑤에서 연결하면 PC 파일에 자동 저장됩니다. 동기화 폴더에 두면 여러 PC에서 쓸 수 있습니다.
- 문장 은행은 엑셀로 내보내 따로 보관할 수 있습니다.

## 다른 교과로 확장
문장은행 엑셀의 「과목」 열에 새 과목명(예: 수학Ⅰ, 기하)으로 행을 추가하고, 프로그램 상단 「과목」을 같은 이름으로 바꾸면 됩니다. 「공통」 문장은 모든 과목에서 같이 쓰입니다.
