# 세특 도우미

`index.html`을 브라우저(크롬·엣지)로 열어 사용합니다. 서버는 필요 없고, 데이터는 브라우저에만 저장됩니다. 처음 열 때 엑셀 라이브러리를 받아야 하므로 인터넷 연결이 필요합니다.

1. **불러오기**: 엑셀을 올린 뒤 시트마다 역할(점수 / 참고 / 사용 안 함)과 열 역할(학번·이름·학급·점수)을 지정합니다.
2. **항목·문장 설정**: 항목마다 1~10단계 변환 방식(상대평가 또는 구간 직접 입력)과 단계 묶음별 문장을 설정합니다.
3. **학생별 작업**: 단계와 문장을 수정하고, 바이트를 확인하고, AI로 다듬습니다.
4. **내보내기·설정**: 엑셀 저장, 바이트 제한, AI API 키, 백업과 불러오기를 합니다.
