학생 점수 엑셀 업로드

시트마다 역할을 지정하세요. 점수 시트: 학생 정보·점수 열을 지정합니다(여러 시트를 고르면 합쳐집니다). 참고 시트: 학생별 메모로 표시됩니다. 같은 양식을 다시 올리면 저장된 설정이 자동으로 적용됩니다.

문장 은행

과목이 공통인 문장은 모든 과목에서, 그 외는 위쪽 과목과 같을 때만 쓰입니다. 엑셀에서 고친 뒤 다시 불러오면 계속 업데이트됩니다.

과목 항목

🤖 기존 세특으로 문장 추가 (AI 분류)

예전에 쓴 세특을 붙여넣으면 AI가 문장을 나누고 일반화해서 항목·단계로 분류합니다. 결과를 확인한 뒤 고른 것만 추가합니다. 학생 이름은 지우고 붙여넣으세요.

추가할 과목

📘 문제 정보

발표 문제 코드(예: 113 = 1번째 발표단원의 13번)별 정보입니다. 문장은행 엑셀의 「문제정보」 시트로 함께 불러오고 내보냅니다. 학생 엑셀 「코멘트 기록」의 코드와 연결되어 ④ 학생별 작업에 「발표한 문제」로 표시됩니다.

점수 열마다 1~10단계 변환 방식과 단계별 문장을 설정합니다. [문장 은행에서 가져오기]로 은행 문장을 불러올 수 있습니다. 문장 안의 {이름} {과목} {항목} {점수} {단계} 또는 {엑셀 열이름}은 실제 값으로 바뀝니다. 위에서부터 차례로 최종 세특에 이어 붙습니다.

    💾 작업 파일 (PC에 자동 저장)

    작업 파일(.json)을 연결하면 수정할 때마다 그 파일에 자동 저장됩니다. 문장 은행·설정·학생 작업이 모두 들어 있습니다. 구글 드라이브나 원드라이브 동기화 폴더에 두면 다른 PC에서도 이어서 쓸 수 있습니다. (크롬·엣지 지원)

    기본 설정

    바이트 제한 (나이스 기준: 한글 3, 영문·숫자·공백 1, 줄바꿈 2바이트)
    AI 세특 작성 목표 분량 ~% (바이트 제한 기준. 나중에 직접 고칠 여유를 두려면 낮게)
    문제 발표 가중치: 기본 도전 (「문제발표 가중점수」 항목 계산에 사용)

    성능 모델

    Claude 구독 모드는 claude.ai에서 이 프로그램(아티팩트)을 열었을 때만 동작하며, 선생님의 Claude 사용량에서 차감됩니다. 처음 사용할 때 허용 창이 한 번 뜹니다.

    ⭐추천: 빠르고 안정적인 모델 · (미리보기): 시험 버전이라 느리거나 막힐 수 있음 · (느림): 깊게 생각하는 모델 · ✅: 연결 테스트 성공. 응답이 60초 넘게 없으면 자동으로 중단됩니다.
    API 키는 이 브라우저에만 저장되며 작업 파일·백업에는 포함되지 않습니다. AI에는 학생 이름을 '학생'으로 바꾼 문장만 전송됩니다. 지시문에 기재요령(기재 원칙·대체표현)이 함께 전달됩니다.

    일괄 처리 간격 초

    요청이 몰려 실패(503·429 등)하면 3초, 8초, 15초 뒤 자동으로 다시 시도합니다. 그래도 안 되면 위 설정에 따라 다른 모델로 바꿔 처리합니다.
